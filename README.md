# Demension Panel

> Агентлесс (agentless) панель управления инфраструктурой **AmneziaWG** (WireGuard с защитой от DPI) с авторизацией, гибким распределением серверов и автообновляемыми подписками для **Incy** и клиентов на ядре **mihomo** (Clash Verge Rev, FlClash и др.).

---

## 🚀 Основные возможности

- 🛡️ **Протокол AmneziaWG 3.x**: параметры обфускации актуальной версии — `Jc`, `Jmin`, `Jmax`, `S1`–`S4`, непересекающиеся диапазоны `H1`–`H4`, защита заголовков `HeaderProtectionKey`, сигнатурные пакеты `I1`–`I5` — с рандомизацией под каждый сервер и проверкой ограничений протокола. Серверы со старыми параметрами 1.x переводятся на 3.x одной кнопкой.
- 🔐 **Авторизация**: вход администратора, защита от перебора пароля, сессии с отзывом при смене пароля.
- 📦 **Установка одной командой**: интерактивный или полностью автоматический `install.sh`.
- 🤖 **Agentless-управление нодами по SSH**: развертывание Docker-контейнера AmneziaWG на удалённых серверах (Ubuntu, Debian, AlmaLinux; **только x86_64**) без сторонних демонов. Всегда ставится актуальный образ `amneziavpn/amneziawg-go:latest`; обновить уже установленную ноду можно кнопкой «Переустановить AWG» (клиенты сохраняются). Ключ SSH-хоста запоминается при первом подключении.
- 🔍 **Подключение уже установленного AmneziaWG**: при добавлении сервера панель сканирует его. Если там уже работает контейнер AmneziaWG (панели или приложения Amnezia), он подключается без переустановки — с ключами, параметрами и существующими клиентами (импортированные клиенты продолжают работать, но их конфигурации панель выдать не может).
- 📥 **Перенос серверов из AmneziaVPN**: вставьте ключи «Поделиться → Полный доступ» (`vpn://…`) — серверы подключатся с ключами, параметрами и клиентами без переустановки, новых клиентов можно создавать в панели.
- 🤝 **Партнёрский доступ между панелями**: выдайте другу токен — его панель сможет создавать клиентов на ваших нодах, а вы увидите этих клиентов, их трафик и сможете их заблокировать.
- 👥 **Выбор нод для каждого пользователя**, лимиты трафика и срок действия подписки.
- 📱 **Автообновляемые подписки**: единая ссылка `/sub/<token>` и QR-код, заголовки `Profile-Update-Interval`, `Profile-Title` и `Subscription-Userinfo`.
- ⚡ **Горячая синхронизация (`awg syncconf`)** без разрыва соединений; если нода недоступна, панель досинхронизирует её автоматически.
- 🔒 **HTTPS**: Let's Encrypt (Cloudflare DNS-01 или HTTP-01) с автопродлением, самоподписанный или свой сертификат. Включается без перезапуска; HTTP и HTTPS работают на одном порту, поэтому выданные ранее http-ссылки подписок не ломаются.

> ⚠️ Секреты (SSH-пароли/ключи, токен Cloudflare) хранятся в БД зашифрованными ключом `data/secret.key`. Делайте резервную копию всего каталога `data/` — без ключа зашифрованные данные не восстановить.

## 🛠️ Быстрая установка панели на сервер (Production)

Требования: Ubuntu / Debian / AlmaLinux, Node.js **≥ 22.13** (устанавливается автоматически).

```bash
curl -sSL https://raw.githubusercontent.com/ghostoftheeleven/demension-panel/main/install.sh | sudo bash
```

Без вопросов (например, для автоматизации):

```bash
curl -sSL https://raw.githubusercontent.com/ghostoftheeleven/demension-panel/main/install.sh | sudo PANEL_PORT=3001 bash
```

Скрипт:
1. Установит Node.js и зависимости, скомпилирует проект.
2. Спросит **порт** панели (по умолчанию 3001) и проверит, что он свободен.
3. **Сгенерирует случайные логин и пароль администратора** (в БД хранится только хэш пароля). Свои значения можно передать
   через `PANEL_USER` / `PANEL_PASSWORD`.
4. Настроит службу **systemd** (`demension.service`) и дождётся, пока панель ответит.
5. Откроет порт панели в UFW/firewalld, если они активны, и настроит fail2ban для SSH (если fail2ban уже есть на сервере —
   его настройки не меняются).
6. **Выведет в консоль адрес панели, логин и пароль.** Пароль показывается один раз — сохраните его. Потерянный пароль заменяет
   `node server/dist/cli/reset-admin.js` (см. ниже).

При повторном запуске скрипт обновит панель, предварительно сохранив резервную копию БД в `data/backups/`; логин и пароль не
меняются (`PANEL_RESET_CREDENTIALS=1` выдаст новые).

### Версии и обновления

Текущая версия панели видна в шапке интерфейса рядом с названием; там же — последняя версия из
[релизов на GitHub](https://github.com/ghostoftheeleven/demension-panel/releases) и ссылка «Доступна vX.Y.Z», если вышло обновление.
Что изменилось в каждой версии — [CHANGELOG.md](CHANGELOG.md). Обновление — повторный запуск команды установки выше. В карточке
сервера показаны версии AmneziaWG на ноде (amneziawg-go, утилиты, дата сборки образа); свежий образ ставит «Переустановить AWG».

Номер `vX.Y.Z`: **X** — сверхкрупные переработки, **Y** — исправления критических уязвимостей и сбоев, **Z** — обычные
исправления и доработки. Проверку обновлений можно отключить: `DEMENSION_UPDATE_CHECK=0` в `server/.env`.

### Если на сервере уже установлен AmneziaWG (например, из приложения AmneziaVPN)

Установка панели **не трогает Docker и существующие контейнеры** — они продолжают работать. Чтобы управлять ими из панели,
добавьте этот же сервер в панели («Добавить сервер»: его адрес и SSH-доступ) — панель найдёт контейнер и подключит его вместе
с клиентами **без переустановки**. Не нажимайте «Установить AmneziaWG» до подключения: панель в этом случае откажется, чтобы
не удалить контейнер приложения (его конфигурация и клиенты лежат внутри контейнера). После подключения не меняйте клиентов
этого сервера в приложении AmneziaVPN — панель перезапишет конфигурацию из своей БД. Подробнее: [docs/amnezia-import.md](docs/amnezia-import.md).

Управление службой:
```bash
systemctl status demension    # Проверка статуса
systemctl restart demension   # Перезапуск
journalctl -u demension -f    # Логи в реальном времени
```

Сброс пароля администратора (без параметров — новый случайный пароль при прежнем логине, он будет показан один раз):
```bash
cd /opt/demension-panel && node server/dist/cli/reset-admin.js
# или свои значения: PANEL_USER=имя PANEL_PASSWORD='новый-пароль' node server/dist/cli/reset-admin.js
```

## 💻 Локальный запуск (Разработка)

```bash
git clone https://github.com/ghostoftheeleven/demension-panel.git
cd demension-panel

npm install --prefix server
npm install --prefix client

npm run dev:server   # Бэкенд на http://localhost:3001
npm run dev:client   # Фронтенд на http://localhost:3000

npm test --prefix server   # Тесты
```

Если `PANEL_USER` / `PANEL_PASSWORD` не заданы, при первом запуске создаётся администратор со случайными логином и паролем — они один раз выводятся в лог.

## 📡 Подписки

Каждый пользователь панели получает постоянную ссылку вида:
```
http(s)://<ВАШ_СЕРВЕР>:<ПОРТ>/sub/<ТОКЕН>
```

Форматы ответа:

| Формат | Как получить | Для каких клиентов |
|---|---|---|
| `awg://<base64url(.conf)>#<имя>`, список в base64 ([спецификация Incy](https://docs.incy.cc/en/subscription-format/)) | по умолчанию | Incy (iOS, Android) |
| YAML mihomo с `amnezia-wg-option` | автоматически по User-Agent или `?format=clash` | Clash Verge Rev, FlClash, Mihomo Party, Clash Meta for Android |
| JSON-контейнер Incy | `?format=json` | Incy |

Название, описание, объявление, ссылки поддержки, сортировка и отображаемые имена серверов (например, с эмодзи флага) настраиваются на странице **«Оформление подписки»**. Заголовки оформления понимает Incy; клиенты mihomo используют только имена серверов.

1. **В Incy** (iOS / Android): добавьте подписку по ссылке или отсканируйте QR-код из панели.
2. При изменении доступных серверов список обновится автоматически (интервал задаётся в настройках панели).
3. Если панель открыта через SSH-туннель или внутренний адрес, укажите **публичный адрес** в «Безопасность → Настройки панели», иначе ссылки будут нерабочими.

> HAPP, v2rayNG и Karing не поддерживают AmneziaWG, а приложения AmneziaWG / Amnezia VPN не умеют подписки по ссылке — для них скачайте `.conf` или отсканируйте QR-код отдельного клиента.

Сброс ссылки подписки перевыпускает и ключи пользователя: старые конфигурации перестают работать.

## 🤝 Партнёрский доступ к нодам

Два администратора со своими панелями могут делиться нодами.

**Владелец нод** («Партнёры» → «Выдать доступ»):
1. Выбирает ноды и при желании лимиты: число клиентов, трафик, срок.
2. Получает строку подключения вида `https://panel-a.example.com#dp_…` (показывается один раз, в БД хранится только хэш токена) и передаёт её партнёру.
3. Видит клиентов партнёра (в списке клиентов ноды и в карточке доступа), их трафик и журнал действий; может заблокировать клиента, отключить или удалить доступ, перевыпустить токен.

**Партнёр** («Партнёры» → «Ноды партнёров»):
1. Вставляет строку подключения — ноды владельца появляются в списке серверов с пометкой «нода партнёра».
2. Выдаёт их своим пользователям как обычные ноды: клиенты создаются автоматически, конфиги, QR и подписки собирает его панель.
3. Ключи клиентов генерируются у партнёра — **приватные ключи не передаются владельцу**, только публичные.

Как это работает:
- Панель партнёра раз в минуту синхронизируется с панелью владельца через API `/api/federation/v1`: получает адреса и параметры обфускации нод, создаёт и удаляет клиентов, забирает трафик и блокировки.
- Если владелец сменит параметры ноды (например, перейдёт на AmneziaWG 3.x), подписки партнёра обновятся автоматически.
- Если панель владельца недоступна, выданные конфиги продолжают работать — трафик идёт напрямую через ноды.
- Обе панели должны работать по **HTTPS**, иначе токен передавался бы открытым текстом. Для локальной разработки: `ALLOW_INSECURE_FEDERATION=1`.
- API защищён ограничением частоты запросов и блокировкой подбора токенов.

## 📥 Перенос серверов из AmneziaVPN

1. В AmneziaVPN: сервер → **«Поделиться»** → **«Полный доступ»** → скопируйте ключ `vpn://…`.
2. В панели: **«Добавить сервер»** → **«Из AmneziaVPN (ключ)»**, вставьте один или несколько ключей.
3. Панель подключится по SSH из ключа, найдёт работающий AmneziaWG и заберёт его ключи, параметры и клиентов.

Клиенты из AmneziaVPN продолжат работать (в панели они помечены «импорт», их конфиги выдать нельзя); новых клиентов
создавайте в панели. После переноса не меняйте клиентов этих серверов в приложении AmneziaVPN — панель перезапишет
конфигурацию. Подробнее — [docs/amnezia-import.md](docs/amnezia-import.md).
