# Demension Panel

> Современная агентлесс (agentless) панель управления инфраструктурой **AmneziaWG** (WireGuard с защитой от DPI) с авторизацией, гибким распределением серверов и автообновляемыми подписками для **HAPP** и **Incy**.

---

## 🚀 Основные возможности

- 🛡️ **Протокол AmneziaWG**: глубокая поддержка всех параметров обфускации (`Jc`, `Jmin`, `Jmax`, `S1`, `S2`, `H1`, `H2`, `H3`, `H4`) с уникальной рандомизацией под каждый сервер.
- 🔐 **Встроенная авторизация**: защищенный вход администратора по логину и паролю, сессионные токены, смена пароля.
- 📦 **Быстрая установка панели одной командой**: интерактивный установочный скрипт `install.sh`, позволяющий выбрать порт и задать учетные данные администратора.
- 🤖 **Agentless-управление нодами по SSH**: автоматическое развертывание изолированных Docker-контейнеров на удаленных серверах (Ubuntu, Debian, AlmaLinux) без установки сторонних демонов.
- 👥 **Выбор доступных нод для каждого пользователя**: администратор галочками выбирает, к каким именно серверам (нодам) имеет доступ конкретный пользователь.
- 📱 **Автообновляемые подписки для HAPP и Incy**:
  - Единая ссылка подписки `/sub/<token>` и QR-код.
  - Поддержка заголовков `Profile-Update-Interval` и `Subscription-Userinfo`.
  - При добавлении или удалении серверов у пользователя в панели список нод в мобильных приложениях обновляется **автоматически**!
- ⚡ **Горячая синхронизация (`awg syncconf`)**: добавление и отключение клиентов без разрыва существующих соединений.

## 🛠️ Быстрая установка панели на сервер (Production)

Для установки на чистый VPS под управлением Ubuntu, Debian или AlmaLinux:

```bash
curl -sSL https://raw.githubusercontent.com/ghostoftheeleven/demension-panel/main/install.sh | sudo bash
```

Скрипт в интерактивном режиме:
1. Запросит **порт** для веб-панели (по умолчанию `3001`).
2. Запросит **логин и пароль** администратора.
3. Установит Node.js и зависимости, скомпилирует проект.
4. Настроит системную службу **systemd** (`demension.service`) с автозапуском при перезагрузке сервера.
5. Откроет порт в фаерволе и выведет готовую ссылку на панель.

Управление службой панели:
```bash
systemctl status demension    # Проверка статуса
systemctl restart demension   # Перезапуск
systemctl stop demension      # Остановка
journalctl -u demension -f    # Просмотр логов в реальном времени
```

## 💻 Локальный запуск (Разработка)

```bash
# Клонирование репозитория
git clone https://github.com/ghostoftheeleven/demension-panel.git
cd demension-panel

# Установка зависимостей
npm install --prefix server
npm install --prefix client

# Запуск в режиме разработки
npm run dev:server   # Бэкенд на http://localhost:3001
npm run dev:client   # Фронтенд на http://localhost:3000
```

## 📡 Подписки для приложений HAPP и Incy

Каждый созданный пользователь панели получает постоянную ссылку вида:
```
http://<ВАШ_СЕРВЕР>:<ПОРТ>/sub/<ТОКЕН>
```

1. **В приложении HAPP / Incy**: нажмите **«+»** &rarr; **«Добавить подписку»** (или отсканируйте QR-код из панели).
2. Приложение загрузит все разрешенные для пользователя серверы с корректными параметрами обфускации AmneziaWG.
3. При изменении доступных серверов администратором в панели, приложение обновит список автоматически благодаря заголовку `Profile-Update-Interval: 12`.
