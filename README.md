# Demension Panel

> Агентлесс (agentless) панель управления инфраструктурой **AmneziaWG** (WireGuard с защитой от DPI) с авторизацией, гибким распределением серверов и автообновляемыми подписками для **Incy**.

---

## 🚀 Основные возможности

- 🛡️ **Протокол AmneziaWG**: поддержка параметров обфускации (`Jc`, `Jmin`, `Jmax`, `S1`, `S2`, `H1`–`H4`) с рандомизацией под каждый сервер и проверкой ограничений протокола.
- 🔐 **Авторизация**: вход администратора, защита от перебора пароля, сессии с отзывом при смене пароля.
- 📦 **Установка одной командой**: интерактивный или полностью автоматический `install.sh`.
- 🤖 **Agentless-управление нодами по SSH**: развертывание Docker-контейнера AmneziaWG на удалённых серверах (Ubuntu, Debian, AlmaLinux; **только x86_64**) без сторонних демонов. Ключ SSH-хоста запоминается при первом подключении.
- 👥 **Выбор нод для каждого пользователя**, лимиты трафика и срок действия подписки.
- 📱 **Автообновляемые подписки**: единая ссылка `/sub/<token>` и QR-код, заголовки `Profile-Update-Interval`, `Profile-Title` и `Subscription-Userinfo`.
- ⚡ **Горячая синхронизация (`awg syncconf`)** без разрыва соединений; если нода недоступна, панель досинхронизирует её автоматически.
- 🔒 **HTTPS**: Let's Encrypt (Cloudflare DNS-01 или HTTP-01) с автопродлением, самоподписанный или свой сертификат. Включается без перезапуска; HTTP и HTTPS работают на одном порту, поэтому выданные ранее http-ссылки подписок не ломаются.

> ⚠️ Секреты (SSH-пароли/ключи, токен Cloudflare) хранятся в БД зашифрованными ключом `data/secret.key`. Делайте резервную копию всего каталога `data/` — без ключа зашифрованные данные не восстановить.

## 🛠️ Быстрая установка панели на сервер (Production)

Требования: Ubuntu / Debian / AlmaLinux, Node.js **≥ 22.13** (устанавливается автоматически).

```bash
curl -sSL https://raw.githubusercontent.com/ghostoftheeleven/demension-panel/main/install.sh | sudo bash
```

Без вопросов (например, для автоматизации):

```bash
curl -sSL https://raw.githubusercontent.com/ghostoftheeleven/demension-panel/main/install.sh | sudo PANEL_PORT=3001 PANEL_USER=admin PANEL_PASSWORD='сложный-пароль' bash
```

Скрипт:
1. Установит Node.js и зависимости, скомпилирует проект.
2. Запросит **порт** панели и **логин/пароль** администратора (пароль не сохраняется в открытом виде).
3. Настроит службу **systemd** (`demension.service`).
4. Откроет порт панели в UFW/firewalld, если они активны, и настроит fail2ban для SSH.

При повторном запуске скрипт обновит панель, предварительно сохранив резервную копию БД в `data/backups/`.

Управление службой:
```bash
systemctl status demension    # Проверка статуса
systemctl restart demension   # Перезапуск
journalctl -u demension -f    # Логи в реальном времени
```

Сброс пароля администратора:
```bash
cd /opt/demension-panel && PANEL_USER=admin PANEL_PASSWORD='новый-пароль' node server/dist/cli/reset-admin.js
```

## 💻 Локальный запуск (Разработка)

```bash
git clone https://github.com/ghostoftheeleven/demension-panel.git
cd demension-panel

npm install --prefix server
npm install --prefix client

npm run dev:server   # Бэкенд на http://localhost:3001
npm run dev:client   # Фронтенд на http://localhost:3000

npm test --prefix server   # Тесты
```

Если `PANEL_PASSWORD` не задан, при первом запуске создаётся администратор `admin` со случайным паролем — он один раз выводится в лог.

## 📡 Подписки

Каждый пользователь панели получает постоянную ссылку вида:
```
http(s)://<ВАШ_СЕРВЕР>:<ПОРТ>/sub/<ТОКЕН>
```

Формат соответствует [спецификации Incy](https://docs.incy.cc/en/subscription-format/): по одной ссылке `awg://<base64url(.conf)>#<имя>` на сервер, список в base64. `?format=json` отдаёт JSON-контейнер Incy.

1. **В Incy** (iOS / Android): добавьте подписку по ссылке или отсканируйте QR-код из панели.
2. При изменении доступных серверов список обновится автоматически (интервал задаётся в настройках панели).
3. Если панель открыта через SSH-туннель или внутренний адрес, укажите **публичный адрес** в «Безопасность → Настройки панели», иначе ссылки будут нерабочими.

> HAPP не поддерживает AmneziaWG — подписка в нём работать не будет. Для отдельных устройств можно скачать `.conf` или отсканировать QR-код в приложении **AmneziaWG**.

Сброс ссылки подписки перевыпускает и ключи пользователя: старые конфигурации перестают работать.
