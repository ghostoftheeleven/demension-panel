# Demension Panel

> Современная агентлесс (agentless) панель управления инфраструктурой **AmneziaWG** (WireGuard с защитой от DPI).

## 🚀 Основные возможности
- **Чисто под AmneziaWG**: глубокая поддержка всех параметров обфускации (`Jc`, `Jmin`, `Jmax`, `S1`, `S2`, `H1`, `H2`, `H3`, `H4`, `HeaderProtectionKey` и др.).
- **Agentless-управление по SSH**: автоматическое развертывание Docker-контейнеров с AmneziaWG на любых Linux-серверах (Ubuntu, Debian, AlmaLinux и др.) без необходимости устанавливать дополнительные агенты.
- **Горячая синхронизация (syncconf)**: добавление, отключение и удаление клиентов без перезагрузки интерфейса и без разрыва соединений других пиров.
- **Генератор обфускации**: уникальная рандомизация заголовков и мусорных пакетов для каждого сервера.
- **Управление клиентами**: экспорт конфигураций `.conf`, генерация QR-кодов, учет трафика (RX/TX), контроль последней активности (Handshake).
- **Мультисерверность**: управление распределенным парком серверов из единого веб-интерфейса.

## 🛠 Технологический стек
- **Backend**: Node.js, Fastify/Express, TypeScript, `ssh2`
- **Database**: SQLite (WAL mode, легкость, автономность)
- **Frontend**: React, Tailwind CSS, Lucide Icons, Vite
- **Server Runtime**: Docker (`amneziavpn/amneziawg-go:latest`) + `awg-tools`
