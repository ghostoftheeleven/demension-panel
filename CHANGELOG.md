# История изменений

Формат версий `vX.Y.Z` и правила выбора номера — в [docs/releases.md](docs/releases.md). Каждая версия публикуется на GitHub
как релиз; текст релиза берётся из соответствующего раздела этого файла.

## v0.1.4 — 2026-10-25

Проект переименован в **Dementia**, новое оформление Bento.

### Переименование
- Панель теперь называется **Dementia Panel**, репозиторий — `ghostoftheeleven/dementia-panel` (старые ссылки GitHub перенаправляет).
- Обновление переносит установку сама: `/opt/demension-panel` → `/opt/dementia-panel` (старый путь остаётся ссылкой), служба
  `demension.service` → `dementia.service` (старое имя работает как псевдоним: `systemctl restart demension` по-прежнему действует),
  переменные `DEMENSION_*` в `server/.env` → `DEMENTIA_*`, файл БД `demension.db` → `dementia.db`. Данные, логин, ноды и подписки
  не меняются; входить заново не нужно.
- Группа серверов в подписке mihomo (Clash) называется «Dementia».
- Ноды не переустанавливаются и не перезапускаются. Архивы переноса прежних версий по-прежнему принимаются.

### Интерфейс
- **Оформление Bento** вместо neo-brutal: тёмный фон, плитки с крупным скруглением, сочные акценты (лайм, оранжевый, голубой),
  заголовки Unbounded, кнопки-пилюли. На экране «Серверы» — плитки сводки: состояние сети, клиенты онлайн, ноды, требующие внимания,
  версии AmneziaWG.
- Шрифты по-прежнему поставляются вместе с панелью (Onest, Unbounded, JetBrains Mono).

### После обновления
- Обновить можно кнопкой в панели (с v0.1.2) или командой установки. В командах используйте новые имена (`systemctl status dementia`,
  `/opt/dementia-panel`); старые продолжат работать.

## v0.1.3 — 2026-10-25

Новое оформление панели.

### Интерфейс
- **Полный редизайн в стиле neo-brutal:** светлый «бумажный» фон, чёрные рамки, жёсткие тени, яркие плоские цвета разделов, шрифты
  Rubik и JetBrains Mono. Все функции и расположение элементов остались прежними.
- Шапка в две строки: сводка и действия сверху, разделы — отдельной строкой. **На телефоне разделы теперь доступны** (раньше вкладки
  на узком экране были скрыты) — строка разделов прокручивается.
- Флаги стран отображаются и в Windows (локальный шрифт Twemoji Country Flags).
- Шрифты поставляются вместе с панелью: ничего не загружается из интернета, CSP не ослаблялась.
- Исправлена горизонтальная прокрутка на узких экранах в разделах «Пользователи» и «Безопасность».

## v0.1.2 — 2026-10-25

Обновление панели прямо из интерфейса.

### Возможности
- **Обновление из панели.** Значок «Доступна vX.Y.Z» в шапке открывает окно обновления: что нового, кнопка «Обновить», ход
  обновления и журнал. Панель ставит последний релиз тем же `install.sh`, что и из терминала: резервная копия БД, сборка,
  перезапуск. Логин, пароль, ноды, клиенты, подписки, настройки, сертификат и `server/.env` сохраняются; VPN пользователей не
  прерывается. Если новая версия не соберётся или не запустится — панель сама вернётся на прежнюю версию и прежнюю БД.
- `install.sh` умеет обновлять до конкретного релиза: `PANEL_UPDATE_REF=vX.Y.Z`.
- Обновление из интерфейса доступно для панелей, установленных `install.sh` (служба systemd, клон git). Отключить:
  `DEMENSION_SELF_UPDATE=0` в `server/.env`.

### После обновления
- До v0.1.2 обновите панель как раньше — командой установки из терминала; следующие версии можно ставить из интерфейса.

## v0.1.1 — 2026-10-25

Перенос панели на другой сервер, смена логина администратора и проверка доступности нод из разных стран.

### Возможности
- **Перенос панели на другой сервер.** На прежней панели («Безопасность → Перенос панели на другой сервер») выдаётся код переноса; на новом
  сервере тот же `install.sh` в режиме «Перенос» забирает всё: логин и пароль администратора, ноды (с SSH-доступами), клиентов,
  пользователей и подписки, партнёров, токен Cloudflare, настройки и ключ шифрования. Данные передаются зашифрованными кодом переноса
  (в том числе по обычному HTTP). Пока архив передан, прежняя панель не принимает изменения, после переноса — замораживается, а её ссылки
  подписок перенаправляются на новый адрес. Автоматический режим: `MIGRATE_FROM`, `MIGRATION_CODE`, `PANEL_CERT_MODE`… Подробнее — `docs/migration.md`.
- **Сертификат при переносе.** Установщик спрашивает способ в терминале: Let's Encrypt через Cloudflare API (сохранённый в прежней панели
  токен используется сам; домен можно указать новый), Let's Encrypt по HTTP-проверке, самоподписанный на IP, свой сертификат (путь к
  файлам на новом сервере), а также оставить сертификат прежней панели или продолжить без HTTPS.
- **Смена логина администратора** («Учётная запись» в шапке, рядом со сменой пароля) — по текущему паролю; остальные сессии завершаются.
- **Доступность нод из стран.** В разделе «Серверы» выберите до 8 стран — панель проверяет через check-host.net (ping или TCP-порт ноды),
  достучались ли до ноды оттуда. Результаты видны на карточках нод и в подписке: к названию ноды добавляется «🇷🇺✅ 🇰🇿❌», к описанию —
  пояснение. Выключено по умолчанию (адреса нод уходят на check-host.net); показывает блокировку адреса ноды, но не протокола. Подробнее — `docs/probes.md`.
- Предупреждение в разделе «Безопасность»: подписки по `https://` с самоподписанным сертификатом на IP работать не будут.

### Безопасность и надёжность
- Неверные пароли при смене логина/пароля и выдаче кода переноса ограничены (5 за 15 минут на администратора).
- **Исправлено:** обновление панели с включённым HTTPS через `install.sh` завершалось ошибкой «Панель не отвечает» (проверка запуска по HTTP
  получала 403), хотя панель работала. Теперь `/api/health` доступен и по HTTP.
- Сертификаты без поля CN (современный Let's Encrypt) получают имя из SAN.

### После обновления
- Миграция БД (v8) применяется сама. Проверка из стран и перенос ничего не меняют, пока вы их не используете.

## v0.1.0 — 2026-10-24

Первый релиз: всё, что было сделано до введения версий.

### Возможности
- Развёртывание AmneziaWG в Docker на нодах по SSH, синхронизация клиентов без разрыва соединений, применение параметров
  обфускации, мониторинг нод и учёт трафика.
- Параметры AmneziaWG 3.x для новых серверов, переход 1.x → 3.x по кнопке.
- Подключение уже установленных контейнеров AmneziaWG (в т.ч. приложения AmneziaVPN) и импорт по ключам «Полный доступ».
- Пользователи с автообновляемыми подписками (Incy, mihomo, JSON), лимиты трафика и срока, оформление подписки.
- Партнёрский доступ к нодам между панелями.
- HTTPS (Let's Encrypt, Cloudflare, свои сертификаты) на одном порту с HTTP для подписок, fail2ban.
- Отображение версии панели, последней версии на GitHub и версий ПО AmneziaWG на нодах.

### Безопасность и надёжность
- Шифрование SSH-доступов и токенов в БД, хэши токенов сессий и партнёров, CSP, проверка данных от панелей партнёров.
- Случайные логин и пароль администратора при установке; установка не удаляет чужой контейнер AmneziaWG.
- Если ноде не удалось применить новый порт или параметры, они возвращаются к прежним — подписки не раздают то, чего нет
  на ноде.
- `install.sh`: обновление скачивается до остановки службы, добавленные вручную переменные `.env` сохраняются.
